Vig = sum of implied probabilities across both sides, minus 1 — the bookmaker's built-in margin. Exact vig needs both sides' odds, which vlr.gg only shows while a match is still upcoming/live; once it finishes, only the winner's payout survives, so older matches show an estimated vig (the recent average for that book, ± its sample standard deviation) applied to the known winner-side odds instead. Spread is how much the available books disagree on this match's fair (de-vigged) probability — only shown where 2+ books have a reading.
low (vig <5% / spread <2pp) mid (vig 5–9% / spread 2–4pp) high (vig ≥9% / spread ≥4pp) est. = estimated, not measured on this match

Tests whether a simple team-map win-rate model predicts each ban in the veto, at every ban position (not just the first). Two competing rules: own worst — ban the available map you personally have the lowest win rate on — vs. deny opponent's best — ban the map your opponent is strongest on. Win rates are computed walk-forward (only from matches strictly before the one being tested, no lookahead) using each team's real tag fetched from its vlr.gg team page. "Clean" excludes cases where the rule's prediction was a tie broken arbitrarily — a purer read on real signal.

Significance: green = p<0.05 vs. the random-guess baseline for that ban's pool size; amber = p<0.10 (suggestive, not conventionally significant); grey = no detectable signal. With 16 comparisons run across positions/rules/variants, only p below roughly 0.003 survives a strict Bonferroni correction — treat single-cell significance with that in mind, and weight consistency across positions more heavily than any one cell.

Fitted model: one test instead of many

Instead of testing rules one at a time, this fits a 2-parameter softmax model — own weakness and opponent strength as features, both continuous, both shrunk toward each team's global (all-map) win rate by empirical-Bayes shrinkage — and compares it against the uniform-over-pool null via a single likelihood-ratio test. kappa (the shrinkage strength) and the coefficients are fit on one slice of the data and reported on a separate, untouched final slice, so nothing here is in-sample.

Decision n (fit / select / test) Best κ β own weakness β opp. strength LR stat p-value

Bans converge cleanly to an interior κ=0.3 — both features matter, own-weakness about 5x more than opponent-strength, and the fit is stable if you perturb the search grid. Picks are also significant, but the fit is degenerate: held-out likelihood keeps improving as κ grows without ever peaking, meaning picks are driven mostly by each team's overall strength rather than map-specific history the way bans are — take the significance as real, but not the specific coefficient magnitudes, which are an artifact of that unbounded limit rather than a stable estimate.
